# Ciencia de Datos - Semana 8

## Descripción del proyecto
Este proyecto tiene como objetivo analizar el desempeño operacional y ambiental de plantas de tratamiento de aguas residuales de la empresa AquaLimpia S. A., utilizando herramientas de ciencia de datos en Python.

El análisis busca identificar patrones relevantes en variables críticas como:
- Demanda Biológica de Oxígeno (DBO)
- Caudal de entrada
- Eficiencia del tratamiento
- Cumplimiento normativo
- Consumo energético
- Generación de lodos

## Objetivos
- Analizar el comportamiento de las plantas de tratamiento.
- Generar reportes para el área de Operaciones y Gestión Ambiental.
- Construir dashboards exploratorios.
- Implementar un flujo de trabajo reproducible utilizando Git y GitHub.

## Tecnologías utilizadas
- Python
- Pandas
- Matplotlib
- Seaborn
- OpenPyXL
- Git
- GitHub
- Visual Studio Code
